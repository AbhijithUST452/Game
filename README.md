# The Schrodinger Paradox

Open `index.html` in Chrome or Edge. For best results, serve the folder with a local web server.

## Assets
Place `cat.png`, `schrodinger.png`, and `suck_it.png` in `assets/`.

## Controls
- Solo Schrodinger: Arrow keys, hold/release Shift
- Solo Cat: Arrow keys, Shift to dash
- Multiplayer: Schrodinger uses arrows + Right Shift; Cat uses WASD + Left Shift
